## ข้อสรุป (แก้แล้ว 2026-09-10)

**ไม่มีกลยุทธ์อยู่ตั้งแต่แรก** — ข้อมูลชุดนี้คือบันทึกการเรียนรู้แบบ discretionary
ไม่ใช่ผลการรันระบบ จึงสรุปเรื่อง edge ของ setup ไม่ได้เลย

สิ่งที่สรุปได้จริงมี 3 ข้อ:

1. **โครงสร้างต้นทุนคือข้อจำกัดหลัก** — เทรด 3,709 oz ด้วย TP เฉลี่ย $6 ทำให้สเปรด
   กินราว 4% ของเป้าหมายทุกไม้ ที่ความถี่ 17.7 ไม้/วัน คิดเป็นหลายร้อยถึงพันดอลลาร์
2. **ระดับ RR ที่ตั้งโดยสัญชาตญาณใช้ได้** — SL $3.55 / TP $6.14 → RR 1.73 สมเหตุสมผล
3. **มีอคติฝั่ง sell** — 1,999 sell vs 1,461 buy ในตลาดขาขึ้น, ฝั่ง sell เสีย -$1,383
   (EA จะตัดปัญหานี้ทิ้งอัตโนมัติ)

### นัยต่อการออกแบบ EA

ตัวเลขต้นทุนชี้ทางออกแบบชัดเจน:

| ดีไซน์ | TP | สเปรดคิดเป็น |
|---|---|---|
| ที่ทำจริง (scalp 5 นาที) | ~$6 | ~4.2% ต่อไม้ |
| ที่ควรเป็น | $15–20 | ~1.3–1.7% ต่อไม้ |

ATR M5 ของทองราว $2–4, H1 ราว $8–15 → เป้า $15–20 คือการเคลื่อนไหวระดับหลายชั่วโมง
การลดความถี่จาก 17.7 เหลือ 1–3 ไม้/วัน ประหยัดสเปรดราว $800 ต่อ 10 เดือน
**โดยไม่ต้องทายถูกขึ้นเลยแม้แต่ไม้เดียว**

### หลักที่ EA จะยึด

1. **ทุกไม้มี SL + TP ตั้งแต่วินาทีที่เข้า ไม่มีข้อยกเว้น**
2. **ห้ามปิดมือก่อนถึง TP/SL** — หรือถ้าจะออกก่อน ต้องเป็นกฎที่เขียนไว้ล่วงหน้า
3. **ขยาย TP ให้สัมพันธ์กับสเปรด** (เป้า TP $12–25, SL $6–12, RR ~1.7–2.0)
4. **Bias filter จาก H1/H4**
5. **Daily loss limit เป็น circuit breaker** — กันตลาดผิดปกติ/บั๊ก ไม่ใช่การจำกัดพฤติกรรม
6. พิจารณา filter รายชั่วโมง/วัน (หลังยืนยัน GMT offset แล้ว)

**ยกเลิก:** ข้อเสนอเดิมเรื่อง "จำกัดไม้ต่อวัน ≤5" และ "cooldown หลังขาดทุน" — ทั้งคู่เป็น
การรักษาปลายเหตุของการเทรดแบบไม่มีแผน ถ้าเกณฑ์เข้าเข้มงวดพอ ความถี่จะลดลงเอง
เป็นผลลัพธ์ ไม่ใช่เป้าหมาย (ผู้ใช้เป็นคนชี้ประเด็นนี้ และถูกต้อง)

### ข้อจำกัดของการวิเคราะห์นี้

- ข้อมูลมีแค่ไม้ที่ **เข้าจริง** ไม่มีไม้ที่ข้าม → **พิสูจน์ไม่ได้ว่า setup มี edge จริง**
  ต้องรอ backtest กฎเต็มใน Phase 1
- ตัวเลขรายชั่วโมงยังอิงเวลา server ที่ยังไม่ยืนยัน offset
- ยังไม่รู้สเปรด/stops level จริงของ FBS
- ไม่รู้ว่าผู้ใช้ใช้กฎอะไรเข้าไม้ จึงแยกไม่ได้ว่า "ไม่ตั้ง TP" คือเข้านอกแผน
  หรือเป็นกลยุทธ์ที่ตั้งใจ
