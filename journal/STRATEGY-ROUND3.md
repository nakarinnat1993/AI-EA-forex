# STRATEGY — รอบที่ 3: FVG + pullback ตัวกรองความผันผวน

**สถานะ:** ล็อกกฎแล้ว 2026-09-19 **ก่อนเขียนโค้ดและก่อนเห็นผล**
**ที่มา:** ผู้ใช้เลือก "ทำทั้ง 2 อย่าง" หลังดูคลิป YouTube ที่ใช้ FVG + CHoCH/OB (DECISIONS 2026-09-19)
**trial:** 2 ครั้ง (สะสมเป็น 15) — ไม่มี variant ต่อจากนี้ถ้าไม่ผ่าน

เกณฑ์ขั้น dev เดิมทุกข้อ (DECISIONS 2026-09-17) / TP1-TP2 และ SL ≥ $3 เหมือน pullback v0 ทุกอย่าง

## A. `fvg_v0` — Fair Value Gap (ตามคลิป)

**Timeframe:** เข้าไม้ **M15** (คลิปใช้ M15) / เทรนด์และโซนฝั่งตรงข้ามจาก **H1**
**กลไก:** แท่งที่พุ่งแรงจนทิ้ง "ช่องว่าง" ไว้ แสดงว่ามีแรงซื้อขายไม่สมดุล ราคามักย้อนกลับมาเติมช่องว่าง
แล้ววิ่งต่อทางเดิม

ฝั่ง Buy (ฝั่ง Sell กลับด้าน) — ตรวจที่แท่ง i ที่เพิ่งปิด:
1. **Bullish FVG:** `low[i] > high[i-2]` และแท่ง i-1 เป็นแท่งเขียว (แท่งที่พุ่งจนเกิดช่องว่าง)
   ช่องว่าง = `high[i-2]` ถึง `low[i]`
2. เทรนด์ H1 เป็นขาขึ้น / แท่ง i อยู่ในช่วง 07:00–16:00 server
3. **Buy Limit ที่ขอบบนของช่องว่าง** (`low[i]` — จุดที่ราคาย่อลงมาแตะก่อน)
4. **SL** = ใต้ `min(low[i-2], low[i-1])` − 0.1 × ATR(14) (ต้นทางของแรงพุ่ง)
5. **TP1/TP2** เหมือน pullback v0: TP1 ก่อนโซน H1 ฝั่งตรงข้าม อย่างน้อย 1R ไม่เกิน 2R / TP2 = 2 เท่าของ TP1
6. ยกเลิกคำสั่งรอเมื่อ: 36 แท่ง, ราคาถึง TP1 ก่อน, **ปิดหลุดขอบล่างของช่องว่าง**, ช่วงข่าว

ไม่มีขนาดช่องว่างขั้นต่ำ (กฎ SL ≥ $3 กรองช่องว่างจิ๋วอยู่แล้ว)

## B. `pullback_v0_volfilter` — pullback เทรนด์ M15 + เทรดเฉพาะช่วงผันผวนสูง

**ฐาน:** IT-009 (`pullback_v0@M5/biasM15`) กฎเดิมทุกข้อ + ตัวกรอง 1 ข้อ
**⚠️ ไอเดียเกิดหลังเห็นผล IT-009** (กำไรกระจุกในปีผันผวน) → ผลขั้น dev ดูดีเกินจริงได้ holdout คือตัวตัดสิน

**ตัวกรอง:** เปิด breakout ได้เฉพาะเมื่อ
`ATR(14) ÷ ราคาปิด` บน M15 **สูงกว่า median ของค่าเดียวกันย้อนหลัง 365 วัน**
(วัดเป็นสัดส่วนของราคา จึงเทียบข้ามปีที่ทองราคาต่างกันได้ / ใช้เฉพาะแท่ง M15 ที่ปิดแล้ว)

**กลไก:** การเทรดตามเทรนด์ต้องมีแรงส่ง ช่วงตลาดนิ่ง breakout มักหลอก

## Holdout

ถ้าตัวใดผ่านขั้น dev → เปิด holdout **ครั้งเดียว** ประเมินทุกตัวที่ผ่านพร้อมกันในการเปิดครั้งนั้น
ตัวที่ผ่านต้องได้ expectancy > 0R และไม่ต่ำกว่า median ของรอบสุ่มบน holdout
**ข้อจำกัดที่รู้ล่วงหน้า:** holdout 4.5 เดือนจะมีไม้ไม่มาก การสอบจึงเข้มได้ไม่เท่าที่ควร
ถ้าผ่าน → ยังต้อง forward test บนพอร์ตเซนต์ก่อนเพิ่มเงิน ไม่ใช่เพิ่มทุนทันที
