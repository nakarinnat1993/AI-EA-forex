# Holdout Log

ช่วงข้อมูล holdout (ตั้งใน `config/data_split.json`) เปิดดูได้ **ครั้งเดียว** ตลอดโปรเจกต์
ผ่าน `research.data.loader.open_holdout()` ซึ่งจะเขียนบันทึกลงไฟล์นี้อัตโนมัติ
และปฏิเสธการเปิดครั้งที่สอง

ถ้าผลบน holdout ไม่ผ่าน → กลับไปคิดใหม่ **ไม่ใช่ปรับจนผ่าน**
และ holdout ชุดนี้ใช้ยืนยันอะไรไม่ได้อีกแล้ว
