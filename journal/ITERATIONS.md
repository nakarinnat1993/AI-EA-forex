# Iteration Log

บันทึกทุกครั้งที่ใช้ผล backtest ในการตัดสินใจ — **รวมครั้งที่ผลแย่และถูกทิ้งด้วย**

`reports/runs.jsonl` นับจำนวน run ให้อัตโนมัติ (ห้ามลบบรรทัด)
ไฟล์นี้บันทึกสิ่งที่ตัวเลขบอกไม่ได้: *ทำไม* ถึงลอง และ *ตัดสินใจอะไร*

ยิ่งจำนวน trial สะสมมาก ผลที่ดีที่สุดยิ่งมีโอกาสเป็นความบังเอิญ → ต้องหักส่วนลด

---

## รูปแบบ

```
### IT-001 — YYYY-MM-DD — <ชื่อสั้น>

- **สมมติฐาน:** อะไร และเหตุผลเชิงกลไกตลาด (ไม่ใช่ "ลองดู")
- **เปลี่ยนอะไร:** พารามิเตอร์/ตรรกะที่ต่างจากรอบก่อน
- **run ids:** จาก reports/runs.jsonl
- **ผล (walk-forward):** expectancy R, PF, max DD, จำนวนไม้ แยกทุก fold
- **ตัดสินใจ:** เก็บ / ทิ้ง / ทดสอบต่อ — พร้อมเหตุผล
- **trial สะสมของกลยุทธ์นี้:** N
```
