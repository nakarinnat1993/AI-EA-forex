# Iteration Log

บันทึกทุกครั้งที่ใช้ผล backtest ในการตัดสินใจ — **รวมครั้งที่ผลแย่และถูกทิ้งด้วย**

`reports/runs.jsonl` นับจำนวน run ให้อัตโนมัติ (ห้ามลบบรรทัด)
ไฟล์นี้บันทึกสิ่งที่ตัวเลขบอกไม่ได้: *ทำไม* ถึงลอง และ *ตัดสินใจอะไร*

ยิ่งจำนวน trial สะสมมาก ผลที่ดีที่สุดยิ่งมีโอกาสเป็นความบังเอิญ → ต้องหักส่วนลด
