# STRATEGY — SMC v0

**สถานะ:** ร่าง รอผู้ใช้ดู — ยังไม่ได้เขียนโค้ด ยังไม่ได้ backtest
**วันที่:** 2026-09-15
**ที่มาของกฎ:** Claude ประกอบจากนิยาม SMC ที่ใช้กันแพร่หลาย (ไม่ใช่กฎส่วนตัวของผู้ใช้ และไม่ใช่
การลอก EA สำเร็จรูปของใคร) — SMC บน internet มีหลายสำนัก ทุกจุดที่สำนักต่าง ๆ ตีความไม่ตรงกัน
เลือกค่าเริ่มต้นหนึ่งแบบพร้อมเหตุผล และเก็บทางเลือกอื่นไว้เป็น variant ให้ backtest ตัดสิน

นิยามที่ผู้ใช้ให้มาและตรงกับ SMC ทั่วไปอยู่แล้ว เก็บไว้: BOS/CHoCH นับเมื่อปิดทะลุ, เข้าที่
order block, SL วางตามโครงสร้าง (ใต้/เหนือ order block), ไม่ใช้ FVG

## Timeframe

- **H1** — ทิศทางหลัก (bias)
- **M5** — หา setup และจุดเข้า

## นิยามพื้นฐาน

| คำ | นิยามที่ใช้ในโค้ด |
|---|---|
| **Swing high** | แท่งที่ high สูงกว่า high ของ `L` แท่งทางซ้ายและ `L` แท่งทางขวา |
| **Swing low** | กลับด้านของ swing high |
| **การรู้ว่าเป็น swing** | รู้ได้หลังแท่งทางขวาครบ `L` แท่งเท่านั้น — ห้ามใช้ก่อนนั้น (กัน look-ahead) |
| **BOS / CHoCH** | ราคา **ปิด** ทะลุ swing ล่าสุดที่ยืนยันแล้ว ไส้ทะลุอย่างเดียวไม่นับ / BOS = ทะลุไปทางเดียวกับเทรนด์, CHoCH = ทะลุสวนเทรนด์เดิม |
| **Bias H1** | ขาขึ้น = การทะลุโครงสร้าง H1 ครั้งล่าสุดเป็นการปิดทะลุ swing high / ขาลงกลับด้าน |
| **Liquidity** | Asian high/low (00:00–07:00 server) และ high/low ของวันก่อนหน้า |
| **Order block (ขาขึ้น)** | แท่งแดงแท่งสุดท้าย (close < open) ก่อนราคาเริ่มพุ่งขึ้นไปทำ CHoCH โซน = **ทั้งแท่ง** (high ถึง low) |

## Setup ฝั่ง Buy (ฝั่ง Sell กลับด้านทุกข้อ)

1. **Bias H1 เป็นขาขึ้น**
2. **Sweep:** ราคา M5 **มาจากด้านบน** (แท่งก่อนหน้าปิดเหนือระดับ) ทิ่มลงทะลุ liquidity ฝั่งล่าง
   (Asian low หรือ low ของเมื่อวาน) แล้ว **ปิดกลับขึ้นมาเหนือระดับนั้น** ภายใน `reclaim_bars` แท่ง
   (ปิดกลับในแท่งเดียวกันก็นับ) — liquidity หนึ่งระดับถูกเก็บได้ครั้งเดียว หลัง sweep สำเร็จหรือ
   ทะลุจริงแล้ว ระดับนั้นใช้ไม่ได้อีกจนกว่าจะเปลี่ยนวัน/session *(v0.1)*
3. **CHoCH:** หลัง sweep ภายใน `choch_window` แท่ง ราคา M5 **ปิด** ทะลุ swing high ล่าสุดที่ยืนยันแล้ว
4. **หา order block:** แท่งแดงแท่งสุดท้าย **ที่หรือก่อนจุดต่ำสุดของการกวาด** (ต้นทางของแรงกลับตัว)
   ย้อนหาไม่เกิน `choch_window` แท่ง *(v0.1 — v0 ค้นระหว่างจุดต่ำสุดกับแท่ง CHoCH ซึ่งขัดกับตารางนิยาม)*
5. **ตั้ง Buy Limit ที่ขอบบนของ OB** (ขอบที่ราคาย่อลงมาแตะก่อน)
6. **SL** = ใต้ low ของ OB ลงไป `sl_buffer_atr` × ATR(14, M5)
7. **TP** = `tp_r` × ระยะ SL (ค่าเริ่มต้น 2R)

### คำสั่งรอถูกยกเลิกเมื่อ

- ครบ `order_expiry` แท่งแล้วราคายังไม่ย่อมาถึง
- ราคาไปถึงระดับ TP ก่อนย่อมาเข้า (ตกรถ = ปล่อยไป ไม่ไล่ราคา)
- ราคา **ปิด** หลุด low ของ OB ก่อนเข้า (โซนเสียแล้ว)
- เข้าช่วง news blackout

### กฎคงที่ (ไม่ปรับ)

- OB หนึ่งอันใช้ได้ครั้งเดียว
- ถือได้ครั้งละ 1 ไม้ และมีคำสั่งรอได้ครั้งละ 1 คำสั่ง
- หา setup เฉพาะช่วง London–New York: sweep และ CHoCH ต้องเกิดระหว่าง 07:00–16:00 server
- ระยะ SL ต่ำกว่า $3 → ข้าม (สเปรด ~$0.25 จะกินเกิน 8% ของความเสี่ยง)
- news filter: `config/news_filter.json`
- ขนาดไม้: เสี่ยง 1% ต่อไม้ / daily loss limit 3% (ค่าเริ่มต้นที่ผู้ใช้ยังไม่ยืนยัน)

## พารามิเตอร์ที่ปรับได้ (7 ตัว — อยู่ในงบ < 10)

| พารามิเตอร์ | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `swing_len_h1` | 5 | จำนวนแท่งซ้าย/ขวาของ swing บน H1 |
| `swing_len_m5` | 3 | จำนวนแท่งซ้าย/ขวาของ swing บน M5 |
| `reclaim_bars` | 3 | sweep ต้องปิดกลับเข้ามาภายในกี่แท่ง |
| `choch_window` | 24 | CHoCH ต้องเกิดภายในกี่แท่งหลัง sweep (2 ชม.) |
| `order_expiry` | 36 | รอราคาย่อกลับนานสุดกี่แท่ง (3 ชม.) |
| `sl_buffer_atr` | 0.1 | ระยะเผื่อใต้ OB เป็นสัดส่วนของ ATR |
| `tp_r` | 2.0 | TP เป็นกี่เท่าของระยะ SL |

ค่าเริ่มต้นตั้งจากเหตุผลก่อนดูผล — ห้ามเลือกค่าจากการลองหลายค่าแล้วเอาตัวที่ผลดีสุด
โดยไม่บันทึกใน ITERATIONS และนับ trial

## Variant

### เลือกไว้ล่วงหน้าสำหรับรอบนี้ — ล็อก 2026-09-17 ก่อนเห็นผลบนข้อมูล Dukascopy

**กติกา:** ทดสอบ variant ก็ต่อเมื่อ `smc_v0.1` ไม่ผ่านเกณฑ์ขั้น dev เท่านั้น ทดสอบทีละตัวตามลำดับ
แต่ละตัวต้องผ่านเกณฑ์ครบทุกข้อด้วยตัวเอง ไม่ใช่เลือก "ตัวที่ดีที่สุด" จากทั้งหมด
ทุกตัวนับเป็น trial และถ้าผ่านต้องสอบ holdout เหมือนกัน

| # | variant | เหตุผลเชิงกลไก (จากการตรวจกราฟ) |
|---|---|---|
| 1 | **SL ใต้จุดสุดของ sweep** − buffer แทนใต้ OB | 2025-12-08: SL อยู่เหนือไส้ของ sweep ราคาย้อนเก็บ SL ง่ายโดยที่โครงสร้างยังไม่เสีย |
| 2 | **รับเฉพาะ CHoCH** ไม่รับ BOS | BOS หลัง sweep อาจเป็นแค่เทรนด์เดิมไปต่อ ไม่ใช่การกลับตัวที่ SMC ต้องการ |
| 3 | **sweep ต้องทิ่มเกินระดับ ≥ 0.1 × ATR(14)** | 2025-09-25: ทิ่มเกินระดับแค่ไม่กี่เซนต์ เป็น noise มากกว่าการกวาด stop จริง |

### เก็บไว้ ยังไม่ทดสอบในรอบนี้

- เข้าที่กลาง OB (mean threshold) แทนขอบบน
- โซน OB ใช้แค่ตัวเทียน (open–close) แทนทั้งแท่ง
- TP ที่ liquidity ฝั่งตรงข้ามแทน R คงที่
- เพิ่ม equal highs/lows เป็นแหล่ง liquidity
- bias จาก H4 แทน H1
