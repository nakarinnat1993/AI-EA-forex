## ก่อนเริ่มรัน: ต้องตรวจว่า EA ให้ signal ตรงกับ Python

รัน EA ใน Strategy Tester (ปิด news filter เพราะ tester อ่านปฏิทินไม่ได้) ช่วง 2025-01 → 2026-04
แล้วเทียบรายการ signal กับที่ Python สร้างจากข้อมูล Exness ช่วงเดียวกัน
**ต่างกันได้บ้างจากข้อมูลคนละแหล่ง แต่ต้องอธิบายได้ทุกจุด** ถ้าต่างเกิน 20% ของจำนวน signal → แก้ก่อนรันจริง

### ผลเทียบ (2026-09-22) — ✅ ผ่านทั้ง 3 ค่าตั้ง

ตัวเทียบ: `research/experiments/ea_parity.py` / log ทุกรอบเก็บไว้ที่ `reports/parity/`

| ค่าตั้ง | ช่วงทดสอบ | การตัดสินใจของ EA | ตรงกับ Python | ราคา entry/SL/TP |
|---|---|---|---|---|
| pullback M5 / M15 | 2025-06 → 2026-04 | 856 | 99.5% (4 จุดต่างเพราะ lookback) | ต่าง ≤ $0.0005 |
| pullback M1 / M15 | 2025-06 → 2026-09 | 5,335 | **signal 546/546 = 100%** เมื่อใช้ lookback เท่ากัน | ต่าง ≤ $0.0005 |
| fvg M15 / H1 | 2025-06 → 2026-09 | 1,103 | **100%** | ต่าง ≤ $0.0005 |

**สิ่งที่แก้ใน EA ระหว่างเทียบ** (รอบแรกตรง 98.8%):
1. เช็ค session จากเวลาของแท่ง signal ไม่ใช่เวลาที่แท่งใหม่เปิด (ต่างกัน 1 แท่งที่ขอบ 07:00 และ 16:00)
2. นับอายุคำสั่งรอเป็นจำนวนแท่ง ไม่ใช่เวลา และยกเลิกครบ 36 แท่งพอดี (เดิมเกิน 1 แท่ง)
3. มองโซนย้อนหลัง 100,000 แท่งแทน 5,000 + โหลดข้อมูล timeframe เทรนด์เฉพาะตอนเจอ setup

**⚠️ บทเรียนสำคัญ:** Strategy Tester **จำค่า input เก่าไว้** ทุกรอบรันด้วย `InpLookbackBias=5000` ทั้งที่แก้ในโค้ดแล้ว
M1 ได้รับผลหนักสุด — ถ้ามองย้อนหลังแค่ 5,000 แท่ง signal 37% จะเป็นไม้ที่ backtest ไม่เข้า
→ **ตอนลาก EA ใส่กราฟ demo ต้องเช็คว่า `InpLookbackBias = 100000` ทุกกราฟ**
(พิสูจน์แล้วว่าถ้า Python ใช้ 5,000 เท่ากัน signal ของ M1 ตรงกัน 100%)
