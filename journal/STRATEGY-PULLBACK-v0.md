# STRATEGY — Trend Pullback v0

**สถานะ:** ล็อกกฎแล้ว 2026-09-18 **ก่อนเขียนโค้ดและก่อนเห็นผล**
**ที่มา:** ผู้ใช้ขอ *"เทรดตามเทรน รอ pull back/retest"* + *"ซอยไม้ ตั้ง TP1 ก่อนโซนอย่างน้อย 1:1, TP2"*
(DECISIONS 2026-09-18) — Claude แปลงเป็นกฎที่เป็นตัวเลข

**กลไกที่คาดหวัง:** ในเทรนด์ ระดับที่ถูกทะลุมักเปลี่ยนหน้าที่ (แนวต้านเดิมกลายเป็นแนวรับ)
คนที่ตกรถตอนทะลุจะรอซื้อตอนราคาย่อกลับมาทดสอบระดับนั้น ต่างจาก SMC ที่ทดสอบไปแล้วตรงที่
**ไปทางเดียวกับเทรนด์** ไม่ได้รอจับจุดกลับตัว

---

## Timeframe

- **H1** — ทิศทางเทรนด์ (ใช้ `h1_bias` ตัวเดียวกับ SMC)
- **M5** — จังหวะ breakout และจุดเข้า

## Setup ฝั่ง Buy (ฝั่ง Sell กลับด้านทุกข้อ)

1. **เทรนด์ H1 ขาขึ้น** — การทะลุโครงสร้าง H1 ครั้งล่าสุดเป็นการปิดทะลุ swing high
2. **Breakout บน M5:** แท่ง M5 **ปิด** ทะลุ swing high ล่าสุดที่ยืนยันแล้วขึ้นไป (ไปทางเดียวกับเทรนด์ H1)
   → จำระดับที่ถูกทะลุ = `L`
3. **ตั้ง Buy Limit ที่ `L`** — รอราคาย่อกลับมา retest ระดับที่ถูกทะลุ
4. **SL** = ใต้ swing low ล่าสุดที่ยืนยันแล้ว ณ แท่งที่ทะลุ − `sl_buffer_atr` × ATR(14, M5)
   (จุดต่ำของขาที่ทำให้เกิด breakout — ถ้าหลุดตรงนี้ โครงสร้างขาขึ้นของ M5 เสีย)
5. **โซนฝั่งตรงข้าม** = swing high ของ H1 ที่ยืนยันแล้วและอยู่เหนือ `L` ใกล้ที่สุด
6. **TP1 (ปิดครึ่งหนึ่ง)** = ก่อนโซนฝั่งตรงข้าม − `sl_buffer_atr` × ATR แต่ไม่เกิน `tp1_max_r` × ระยะ SL
   - ถ้าโซนอยู่ใกล้กว่า 1R → **ไม่เทรด** (ไม่มีที่ให้ราคาวิ่ง) ตามที่ผู้ใช้ต้องการ TP1 อย่างน้อย 1:1
   - ถ้าไม่มีโซนข้างบน (ราคาทำ high ใหม่) → TP1 = `tp1_max_r` × ระยะ SL
7. **TP2 (ปิดอีกครึ่ง)** = 2 เท่าของระยะ TP1 นับจากจุดเข้า
8. SL เดิมใช้กับทั้งสองส่วน ไม่เลื่อนมาที่ทุนหลังได้ TP1 (v0 — การเลื่อน SL เป็นกฎที่ผู้ใช้ไม่ได้ระบุ)

### คำสั่งรอถูกยกเลิกเมื่อ

- ครบ `order_expiry` แท่งแล้วราคายังไม่ย่อมาถึง `L`
- ราคาไปถึง TP1 ก่อนย่อมาเข้า (ตกรถ = ปล่อยไป)
- ราคา **ปิด** หลุดระดับ SL ก่อนเข้า (โครงสร้างเสียแล้ว)
- เข้าช่วง news blackout

### กฎคงที่ (ไม่ปรับ) — ใช้แบบเดียวกับ SMC เพื่อให้เทียบกันได้

- หา breakout เฉพาะ 07:00–16:00 server (London–New York)
- ถือได้ครั้งละ 1 ไม้ (ซอยเป็น 2 ส่วน) และคำสั่งรอได้ครั้งละ 1 คำสั่ง
- ระยะ SL ต่ำกว่า $3 → ข้าม
- ความเสี่ยงรวมทั้งสองส่วน 1% / daily loss limit 3% / news filter เหมือนเดิม
- ขนาดไม้แบ่งครึ่ง ปัดลงทั้งสองส่วน ถ้าแบ่งแล้วส่วนใดต่ำกว่า 0.01 → ไม่ซอย ใช้ TP1 อย่างเดียว

## พารามิเตอร์ที่ปรับได้ (5 ตัว — อยู่ในงบ < 10)

| พารามิเตอร์ | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `swing_len_h1` | 5 | swing บน H1 (ทั้งเทรนด์และโซนฝั่งตรงข้าม) |
| `swing_len_m5` | 3 | swing บน M5 |
| `order_expiry` | 36 | รอ retest นานสุดกี่แท่ง (3 ชม.) |
| `sl_buffer_atr` | 0.1 | ระยะเผื่อของ SL และ TP1 เป็นสัดส่วนของ ATR |
| `tp1_max_r` | 2.0 | TP1 ไกลสุดกี่ R |

ค่าเริ่มต้นตั้งก่อนเห็นผล ใช้ค่าเดียวกับ SMC ในทุกตัวที่มีความหมายตรงกัน

## Variant timeframe (ผู้ใช้ขอ 2026-09-18) — ล็อกก่อนเขียนโค้ดและก่อนเห็นผล

ผู้ใช้: *"อยากให้ดูเทรนที่ M15 เข้าที่ M5 และ M1"*

| ชื่อ | เทรนด์ + โซนฝั่งตรงข้าม | breakout / retest / SL |
|---|---|---|
| `pullback_v0@M5/biasM15` | **M15** | M5 |
| `pullback_v0@M1/biasM15` | **M15** | M1 |

- กฎทุกข้อเหมือน v0 ทุกประการ พารามิเตอร์ค่าเดิม นับเป็นจำนวนแท่งเท่าเดิม
  (`swing_len_h1` = ความยาว swing บน timeframe ที่ใช้ดูเทรนด์ = 5 แท่ง M15)
- **คงกฎ SL ≥ $3** — ถ้าตัดออก ต้นทุนจะกิน M1 ตามที่ประวัติเทรดมือของผู้ใช้พิสูจน์ไว้ คาดว่า M1 จะได้ไม้น้อย
- `order_expiry` 36 แท่ง = 3 ชม. บน M5 / 36 นาทีบน M1
- นับเป็น 2 trial (สะสมเป็น 13) เกณฑ์เดิมทุกข้อ ไม่มี variant อื่นต่อจากนี้ถ้าไม่ผ่าน
