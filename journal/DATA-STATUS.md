## คุณภาพ

**ความต่อเนื่อง M5:** ช่องว่างข้ามคืน/สุดสัปดาห์ 75 ครั้ง (ปกติ) ช่องว่างระหว่างวัน 293 ครั้ง
เกิน 2 ชม. แค่ 8 ครั้ง ซึ่งทุกครั้งอยู่ช่วง 22:00–23:00 server ของวันหยุดสหรัฐ
(Memorial Day, Thanksgiving, Juneteenth ฯลฯ) → เป็นวันหยุดตลาดจริง ไม่ใช่ข้อมูลขาด

**ความต่อเนื่อง H1:** ช่องว่างเกิน 2 ชม. กระจุกปี 2018–2021 (36–61 ครั้ง/ปี) ปีหลัง ๆ เหลือ 4–7 ครั้ง
ยอมรับได้ แต่ต้องรู้ว่าข้อมูลยุคเก่าหยาบกว่า

**ยืนยัน timezone อีกทาง:** ชั่วโมง 21:00 server มีแค่ 996 แท่ง เทียบกับชั่วโมงอื่น ~4,370
= ช่วงพักรายวันของตลาดทอง (17:00 New York) → **server = UTC** ตรงกับที่สรุปไว้
